# Base Adapter

Blockchain adapter for ORŸA Wallet - Base blockchain integration

## Overview

- **Language:** TypeScript
- **Blockchain:** Base
- **Primary Use:** Transaction execution, DeFi routing, token operations
- **Architecture:** Chain adapter pattern

## Features

- [ ] Wallet operations
- [ ] Transaction signing & execution
- [ ] Balance queries
- [ ] Transaction history
- [ ] Smart contract interactions

## Configuration

See `.env.example` for environment variables.

## Quick Start

```bash
cp .env.example .env
pnpm install && pnpm build
```

## Testing

```bash
pnpm test
```
