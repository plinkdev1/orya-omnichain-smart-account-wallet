# Cardano Adapter

Blockchain adapter for ORŸA Wallet - Cardano blockchain integration

## Overview

- **Language:** Rust
- **Blockchain:** Cardano
- **Primary Use:** Transaction execution, DeFi routing, token operations
- **Architecture:** Chain adapter pattern

## Features

- [ ] Wallet operations
- [ ] Transaction signing & execution
- [ ] Balance queries
- [ ] Transaction history
- [ ] Smart contract interactions

## Configuration

See `.env.example` for environment variables.

## Quick Start

```bash
cp .env.example .env
cargo build
```

## Testing

```bash
cargo test
```
