# Apollo Router - File Index & Documentation

Complete file listing with descriptions for the ORYA Wallet Apollo Router Federation Gateway.

## Configuration Files

### `router.yaml` - Main Router Configuration
- **Purpose**: Apollo Router configuration defining server, CORS, authentication, and rate limiting
- **Size**: ~150 lines
- **Key Sections**:
  - Server binding and GraphQL path
  - Health check endpoint configuration
  - CORS origin and header configuration
  - Authentication plugin with Firebase JWKS
  - Rate limiting with Redis storage
  - Telemetry and logging
- **Status**: ✅ Production Ready

### `supergraph-config.yaml` - Subgraph Registry
- **Purpose**: Defines all federated subgraphs for composition
- **Size**: ~80 lines
- **Key Sections**:
  - 7 subgraph definitions (user, wallet, transaction, protocol, defi, portfolio, fiat)
  - Retry logic with exponential backoff
  - Introspection and composition settings
- **Usage**: `pnpm run compose` to generate `supergraph.graphql`
- **Status**: ✅ Production Ready

### `supergraph.graphql` - Composed Unified Schema
- **Purpose**: Complete GraphQL schema combining all federated subgraphs
- **Size**: ~800 lines
- **Key Sections**:
  - Query type with 50+ queries
  - Mutation type with 40+ mutations
  - Subscription type with 10+ subscriptions
  - 50+ GraphQL type definitions
  - Complete data model for protocol-agnostic wallet
- **Generated By**: `rover supergraph compose --config supergraph-config.yaml`
- **Status**: ✅ Production Ready

## Quick Reference

### Starting Development

```bash
pnpm install          # Install dependencies
pnpm run compose      # Compose supergraph
pnpm run dev          # Start server
```

### Key Endpoints

- **GraphQL**: `POST http://localhost:4000/graphql`
- **Health**: `GET http://localhost:4000/health`
- **Ready**: `GET http://localhost:4000/ready`
- **Metrics**: `GET http://localhost:4000/metrics` (admin)
- **Schema**: `GET http://localhost:4000/schema` (auth)

### Environment Setup

```bash
cp .env.example .env  # Copy template
# Edit .env with your configuration
```

### Docker

```bash
docker-compose up     # Run all services
```
