  TECHNICAL SPECIFICATIONS
================================================================================

Icon Format Details:
  SVG Format:
    - Resolution: Scalable (viewBox definition)
    - Aspect Ratio: 1:1 (square)
    - Color Space: RGB
    - Compression: Valid SVG XML
    - Size per Icon: 50-200 KB (typical)

  PNG Format:
    - 32×32px:  Ultra-compact (badges, lists)
    - 64×64px:  Standard (cards, grids)
    - 128×128px: Large (headers, details)
    - Transparency: Full alpha channel
    - Format: PNG-32 (RGBA)

Manifest Schema:
  {
    "chainName": {
      "canonical_name": "string",        # Official chain name
      "filename": "string",              # Kebab-case filename
      "sha256": "hex",                   # Content hash
      "source": "url | fallback",        # Source URL
      "source_repo": "string",           # Source repo name
      "png": {
        "32": "path",
        "64": "path",
        "128": "path"
      }
    }
  }

Component API:
  <BlockchainIcon
    chainName="ethereum"               # Required: blockchain name (lowercase)
    size={64}                          # Optional: 32, 64, or 128 (default: 64)
    className="..."                    # Optional: Tailwind classes
    preferSvg={false}                  # Optional: SVG over PNG (default: false)
    fallbackColor="..."                # Optional: Custom fallback color
  />

================================================================================
  TROUBLESHOOTING & COMMON ISSUES
================================================================================

Issue: Icons not showing in app
Solution:
  1. Verify chainName is lowercase: ethereum ✅, Ethereum ❌
  2. Check manifest.json in public folder
  3. Inspect browser console for 404 errors
  4. Verify path to manifest: /icons/manifest.json

Issue: Slow icon rendering
Solution:
  1. Use PNG instead of SVG (default behavior)
  2. Pre-load frequently used icons
  3. Verify Next.js Image optimization is enabled
  4. Check CDN caching headers

Issue: Wrong icon displayed
Solution:
  1. Clear browser cache (Ctrl+Shift+Delete)
  2. Check manifest.json for correct mapping
  3. Verify SVG file exists in public folder
  4. Run: npm run fetch-icons to regenerate

Issue: PNGs missing
Solution:
  1. Check png/ directory structure
  2. Run: npm run fetch-icons:png to regenerate
  3. Verify ImageMagick installed (optional, for quality)
  4. Check file permissions on output folder
